# A1 Tech day 2026 — Android

Вариант 1 (без установки ПО): создайте пустой репозиторий на github.com, загрузите в него содержимое этой папки
(включая скрытую папку .github), откройте вкладку Actions -> Build APK -> Run workflow.
Через ~3 минуты скачайте APK из Artifacts (A1TechDay-apk).

Вариант 2: откройте папку в Android Studio -> Build -> Build APK(s).

Чтобы обновить содержимое — замените app/src/main/assets/index.html.
